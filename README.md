# ITE183 Laboratory 2: WebSocket Server

This project implements a small multi-client chat using Bonezegei Scripting Language (BSL). The server listens on port 8000, serves the chat page at `/`, sends a welcome message to each new WebSocket client, broadcasts incoming messages with `server.sendAll()`, logs disconnections, and returns a custom HTTP 404 response for other paths.

## Project files

| File | Purpose |
| --- | --- |
| `app.bzg` | HTTP routes and WebSocket event handlers |
| `package.json` | BSL entry point and `http` dependency |
| `public/index.html` | Browser chat client |
| `public/404.html` | Custom missing-page response |
| `.gitattributes` | GitHub syntax highlighting for `.bzg` files |
| `LICENSE` | MIT license |

The `lib/` directory is generated by the Bonezegei package installer and is ignored by Git. Native library files are platform-specific. The downloaded `.deb` installer is also ignored. This project needs the BSL `http` package, not the similarly named Node.js package.

## Setup and run

The laboratory requires **Bonezegei v1.3.3**. Its [official repository](https://github.com/bonezegei/Bonezegei_Scripting_Language) documents Windows and Linux installers. For this lab, a Linux x86-64 GitHub Codespace is the straightforward route when working from a Mac. Install the interpreter as directed by the course PDF, then run these commands in this project directory:

```sh
bonezegei -v
bzg install
bzg run
```

Confirm that the first command prints `1.3.3`. If `bzg install` does not resolve the manifest dependency, inspect `bzg -list` and the package manager output; the official project also documents `bzg install <package_name>`. Confirm that installation creates `lib/http.bzg` and a Linux-compatible native library before starting the server. Do not use the Linux `.so` from another machine as proof that this environment works.

Open `http://localhost:8000/` locally, or open forwarded port 8000 in GitHub Codespaces. The client uses the page's current host. It selects `ws://` from an HTTP page and `wss://` from an HTTPS page, including the Codespaces forwarded URL.
